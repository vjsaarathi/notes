# What is ML Preprocessing?

ML models only understand numbers. Real-world data arrives broken — missing values, wrong formats, inconsistent labels, wildly different scales. Preprocessing is the work of fixing all of that before training.

> In practice, data scientists spend **60–80% of their time on preprocessing**, not on the model itself.

## The pipeline

```
Raw data  →  Cleaning  →  Feature Engineering  →  Encoding & Scaling  →  Split  →  Model
```

A well-preprocessed simple model usually beats a poorly-preprocessed complex one.

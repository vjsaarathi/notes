# Binary Numbers

Every integer is stored as bits.

Example

```
13

1101
```

Each position is a power of two.

```
128 64 32 16 8 4 2 1
```

Useful facts

```
2^5 = 32
2^6 = 64
2^7 = 128
```

Interview Questions

- Convert decimal to binary
- Explain two's complement
- Why does shifting divide/multiply by powers of two?
- How are negative integers stored?

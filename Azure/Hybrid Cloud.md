## Hybrid Cloud
+ combines both public and private clouds, allowing you to run your applications in the most appropriate locations
+ Helpful when you have some things that cannot be put in the cloud, maybe for legal reasons, compatibility issues etc.
+ Host a public API in the public cloud and then host the Database in a highly secure on premise servers or a private cloud.
### Advantages
+ keeps any system running and accessible that use out-of-date hardware or and out-of-date OS
+ Flexibility with what you run locally and what runs on public cloud
+ take advantage of varying prices that can in some economies would cost you less to host your own infra than hosting it on the public cloud
### Disadvantages
- More expensive than selecting one deployment model since it involves some CapEx cost up front
- More complicated to set up and manage

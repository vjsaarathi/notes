### Cloud basics
#### what's cloud
+ delivery of computing services over the internet, usually with a pay-as-you-go pricing model
+ the real value of the cloud comes from the speed, enables u to solve the business challenges ASAP with cutting edge techs.
#### why should one move to cloud
+ the ability to spin up resources as the demand grows for ur application 
+ ability to deliver updates and features without interrupting the flow of the user based on regional updates and releases, 
+ in case of a failure to deliver a feature or a buggy release, efficient and non nonchalant rollbacks without disturbing the peace of the user.
+ cloud enables a company to serve the user faster based on the region he's from and also enables the company to control what is served to the user
+ the pricing is pay-as-u-go and also according the resource usage which means u don't have to maintain a hefty old server all by urself which is always and cost the same even when the traffic to the server is low.

### Benefits of cloud computing
+ cost effective
+ Scalable
	+ Horizontal Scaling -- adding more servers that function together as one unit
	+ Vertical Scaling -- adding more resources to increase the power of an existing server.
	+ the scaling can be done manually or can be automated via specific triggers.
+ Elastic
	+ u can easily add more resources at peak operating hours and reduce the resources when the traffic normalizes
	+ the payment will be charged for the additional usage of resources only for the time period you've used them.
+ Reliable 
	+ data backup, disaster recovery, data replication services.
	+ Redundancy is built into the cloud platform, if a component fails, we can setup one more backup component to take its place, this is also called as **fault tolerance**.
+ Global
	+ the audience can have a local presence near to the region they're in and can enjoy the best response time.
	+ you can also make sure to reduce/ increase resources based on usage in different regions.
+ Secure
	+ you don't have to spend a single dime on maintaining the facility, the security (both physical and Digital) is completely handled by the provider, you just have to configure it in case of digital security.
